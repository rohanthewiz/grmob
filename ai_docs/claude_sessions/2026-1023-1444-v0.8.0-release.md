## Tag message

```
v0.8.0: cart and checkout, StockTicker, swipes, the share sheet, BibleStudy

One exported signature changed since v0.7.2 (apidiff, outside examples
and internal): htmlout.ZeroesFieldFloor takes the node's flex grow.
Everything else is additions.

Packages
- cart: a shopping-cart model. Items and codes, a pure Reduce over a
  closed set of Actions, and Price running pricing Rules (PercentOff,
  AmountOff, FlatShipping, Tax, or your own) in minor units. cart.Store is
  one shared, subscribable, goroutine-safe cart with a Persister;
  cart/cartdb persists it in bytdb. hooks.UseCart subscribes a screen.

Components (comps)
- CartLine, CartList, CartSummary, CartButton, PromoCodeField
  (OnApplyAsync for a code only a server can check; refusals
  sentence-cased, ErrorText to override) and StripeCheckoutFromCart.
- StockTicker: a sideways tape of quotes, stepped by the caller, with
  RedRises for markets where red means up.
- BibleStudy: a BibleVerse whose verses are tappable rows; a tap opens
  Blue Letter Bible's study tools for that verse (interlinear & Strong's,
  cross-references, commentaries, dictionaries, translations). Verse
  numbers share one right-aligned gutter.
- Gallery steps on a swipe and shares through the system share sheet.

Core and hosts
- core.OnSwipe / OnVerticalSwipe on every host: one report per press, RTL
  resolved, each claiming only its axis so a Scroll still scrolls.
- core.Share opens the system share sheet (Web Share API, Android
  chooser, UIActivityViewController) and reports whether one was shown.
- Web: a growing Text or Column no longer floors at its longest word
  (min-width: 0, as a Compose weight); fixes the CI-only check 24.

blb
- Passage.ChapterID and Passage.StudyURL(verse, tool): any verse of the
  chapter links to its study tab on BLB; Tool* constants name the tabs.

Tutorial
- Lessons 4.42 (StockTicker), 4.43 (shopping cart), 4.44 (BibleStudy):
  87 lessons across 8 chapters.

CI is green, including the EditableGrid -race test (harness fix) and the
site's check 24.
```
