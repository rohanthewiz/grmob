## Stage A — what the canary rests on

The canary decides whether the canvas join bit a face: one string measured
under `INK_CANARY_FALLBACK` alone and under the compositor's family in front of
it, a difference meaning the name reached something. Three of its own premises
were unread.

### Item 1 · the separation

`inkCanvasNameReached` compares the two advances against `LAYOUT_UNIT`.
Everywhere else in the file a LayoutUnit is the width of the answer — two
numbers about one face, and the tolerance keeps the check off a double's last
bits. Here it is a claim about a NOTE: that a fixed-advance face and this grid's
proportional ones are nothing like each other over these strings. A run clearing
a 64th of a pixel has shown nothing of the kind.

    The direction it fails in is the silent one. A face within a LayoutUnit of
    monospace for a badge's single digit makes canary and base one number, every
    join reads as a name that reached nothing, and the run PASSES — a silent
    join is reported, a face that was never held is not.

`INK_CANARY_MARGIN = 0.25`, and `asked.canvasNarrowest` measures the population
against it — the same shape `asked.canvasWidest` gives the join's own bound. The
thinnest canary in the grid, a single-digit badge, separates its advances by
**1.2246px**: about five times the margin, sixteen LayoutUnits above the bound.
Set from that measurement rather than as a fraction of it, for the reason
`INK_ROW_ROUNDING` is.

### Item 2 · the generic

Nothing asked what `monospace` resolves to. A build mapping it onto the family
the text is set in would have the canary comparing a face with itself —
silently, in the direction that reports every run as skipped.

A span in the generic is mounted INSIDE the bracketed window and
`CSS.getPlatformFontsForNode` is put to it, which is the third party every other
face question here goes to. It is invisible to both fingerprints by
construction — they walk `[data-node-path]` and it carries none, and
`position:fixed` takes it out of flow — and the fingerprints are also what would
report the argument wrong: a mount that moved a rect fires `faceLayoutFault`,
which drops every face arm rather than believing this one. Off the left edge
rather than `display:none`, because a box that is not rendered has no glyphs.

    monospace → Menlo on this browser; the grid is Times.

`inkCanvasFallbackFault` has two arms — a read that came back empty (the premise
unmeasured, which is the same silence one level up) and a face the joined runs
share (the trap itself). Asked of the JOINED runs' families, not every face on
the page: a probe drawn in the generic's face costs no canary anything.

### Item 3 · the fold, on both sides

`inkLigatureNote` folded the string and matched the seeds raw. That is right
because `inkLigatureSeeds` is ASCII, which is a property of gen.go's list rather
than of the fold — and a pair added there in a composed form would be looked for
UNFOLDED inside a folded string and never found. The note would then say the
list is short of this face while holding the pair it joined: the same wrong
suspect the fold exists to stop naming, reached from the other end.

Both sides go through `inkFold` now, and a seed the fold changed earns its own
clause — a reader told "fi" is not in a string is owed the form it was looked
for in.

### Item 5 · the kind an exemption lends

Why the population is EXTENSIONS was unwritten. It is a proxy for content: a
kind with an exemption written for it is a kind SHOWN to carry the numbered
prose the arm is about. It cannot see provenance — `core/debug.go` is
hand-written and a generated `zz_gen.go` shares its kind — and that costs the
illustration, never the claim, because the assertion is over the wider union.

Two changes. Only a row the enumeration REACHED lends its kind: a path the walk
never opens is a rename `citationExemptVerdict` is about to report on its own

### Item 6 · a copy placed by the wrong unit

`pinCopyNote` read the lexed file a line at a time; `pinCodeOnly` blanks SPANS.
A phrase inside a string literal on a line that also carries code —
`log("pinSame(total, c.offer)")` — leaves the line live and the copy blanked,
and the note called that copy the surviving assertion and named it as the line
to open. What stands there is the call around the literal.

    pinStripSpaceMap    the raw BYTE every stripped byte came from, beside the line
    pinPhraseCopies     each spelling as lines AND a raw span (was pinPhraseLines)
    pinCopyNote         what the lexer did to those bytes; the line asked second

Three states rather than two: blanked on a line with nothing left (prose),
blanked on a line that kept code (a literal, a trailing comment, or the runaway
that blanks the rest of its own line — and what stands there is not this
string), and not blanked (the line to open). The caller now holds the lexed
source whole; `codeLines` is gone, because a line was the wrong unit.

**Break-tests.** The note put back on lines: `left the copy on [3] standing in
code, so [3] is the line to open` — the fault itself, caught by the new fixture,
which is one `pinCodeOnly` pass over three real spellings. And a span short by a
byte: `the copy on [2] spans "pinSame(total,c.offer"`.

   has more than one.** `inkCanvasFallbackFault` reports the trap when a joined

   trap go unreported, which is the silent direction again. The metric answer is

2. **(age 0 · value low) The canary probe is mounted without a size.** The runs

   stack that maps `monospace` onto different faces by size — optical sizing, a
   family with a display cut — would have the probe answering about a face no
   canary is asked at. `cs.fontSize` is read three lines above for the shorthand
   and nothing carries it to the probe.
3. **(age 0 · value low) gen.go's refusal is still ASCII-shaped and the fold is

   only ever fires because `inkGlyphPerCharacter` let a string through.
   That refusal decides with its own test, in Go, one directory away — so a
   fixture carrying U+FB01 is refused for being outside printable ASCII rather
   than for holding a pair, and a composed form of a pair that IS printable
   ASCII after folding would pass it. The two tests are about one property and
   neither knows the other exists.
4. **(age 0 · value low) One floor for four endings of very different sizes.**
   `affordedEndingFloor` is ten, and the endings score 27, 53, 377 and 473. Ten

   reported by nothing. A floor per ending, or a floor as a fraction of what the
   ending scored when it was measured, is the shape `INK_OWN_MEASURED_ON` uses
   for exactly this: a number taken against one build, named as such.
5. **(age 0 · value low) The lender is the alphabetically first row of its

6. **(age 0 · value low) The shadowed arm lumps three constructs.**
