## N-110: the EditableGrid harness raced its own timer (7bad8db)

`go test -race ./comps` failed in CI on `TestEditableGridBlurCommitsAfterTheGrace`
and `TestEditableGridDiscardIsOneFocusUnitWithTheField`. Every racing pair
ran through the harness's `OnChange`. The blur grace's commit runs on
`UseTimeoutWhile`'s `time.AfterFunc` goroutine and wrote `g.rows` and
`g.changes`, while the test goroutine read them after a `time.Sleep`.

`gridHarness` (comps/editable_grid_test.go) now holds a `sync.Mutex`.

was never racy: a real host serializes callbacks and renders.

## N-109: browser check 24 failed only on Linux fonts (700dc32)

The overflow sweep found Texts spilling their Row on lessons 2.2, 4.29, 5.3
and 6.5, plus 7.2's CheckboxRow and 7.4's PRO badge, at 360/390px, in CI
only. Docker was down, so CI's fonts were approximated instead: the site
page's `font: 14px/1.45 system-ui` was swapped for Verdana (temporarily, then
restored). That reproduced the same eight findings, plus one.

Two causes:

- **A grower's flex floor was its longest word.** BulletList's item Text is
  `FlexGrow(1)`. A flex item's automatic minimum is its min-content width,
  and for text that is its longest word: "core.AccessibilityKeyShortcuts",
  "CalendarHeatmap.WeeksFor:", "core.OnBlur(form.OnBlur(name))". The same
  floor applied to ListRow's growing middle Column on 7.2
  ("UseStyle(Style{BorderRadius:"). `overflow-wrap: break-word` (set on the
  mount point) breaks a word only inside a box that is already narrow
  enough. It does not lower the min-content floor, and `anywhere` was
  rejected earlier for changing every flex item.
  - Fix: any node with `FlexGrow > 0` and no stated MinWidth gets
    `min-width: 0`, in the runtime's `styleFromGrMob` and in htmlout's
    `ZeroesFieldFloor(nodeType, flexGrow)`. This is a Compose weight's
    semantics (the child gets its share, with no content floor). It is
    inert where the node is not a Row's item: min-width is a column's cross
    axis, and a block's automatic minimum is already 0.
- **7.4's title row** could not fit "McGrMob" at Title size beside the
  badge. That row now has `FlexWrap(true)`, so the badge drops a line.

Tests: `TestAGrowerGivesUpItsLongestWord` (htmlout) and

## N-114: `core.Share` (5150eb0)

```
app ──SendSystemEvent("share", {id, text, url})──▶ host
app ◀──ReceiveHostEvent("share", {id, ok})──────── host
```

- **core/share.go**: `Share(text, url string, done func(ok bool))`, in
  ReadClipboard's mould (a correlation id; registered before the send; no
  host or nothing to share → done(false) at once). It needs an answer
  because a desktop browser may have no Web Share API, and a share button
  that does nothing there would be a defect. ok means *a sheet was shown*,
  and a dismissal counts as shown, so a caller's fallback runs only where
  no sheet could be. Routed in `host_events.go`. Listed under the "device"
  API topic.
- **Web** (`grmob-runtime.js`, `GrMob.share`): `navigator.share` with only
  the set fields. It answers ok:false when the API is missing, when
  `canShare` says no, or on any rejection except AbortError. A refusal
  answers in a microtask, as the keystore's does.
- **Android** (`Share.kt`): ACTION_SEND text/plain, with text and url joined
  by a newline, through `Intent.createChooser(send, null)` with
  FLAG_ACTIVITY_NEW_TASK. ok means startActivity did not throw.
- **iOS** (`Share.swift`): a UIActivityViewController with text and URL as
  separate items (so Messages gets a link preview), presented over the top
  presented controller. On iPad it is a popover anchored at the centre with
  no arrow. ok goes back in the present completion.
- **comps.Gallery**: the default Share now calls core.Share. On ok:false it
  falls back to the old behaviour (clipboard, haptic, toast).
  `galleryShareParts` splits the text from the link for the sheet. The
  docs, the components page and lesson 4.41's prose say so, and the stale
  "core has no swipe gesture" line on the components page went too (N-112
  added one).
- Tests: core/share_test.go, the Gallery test with a host that answers
  true and then false, wasm/verify/share_test.mjs, and
  mobile/verify/share_test.go (spellings, plus the dispatch and attach
  lines on all shells).
  - New: `TutorialShareSheetUITests`, which passed on the iOS 26.5
    simulator. The shot shows the sheet with the picsum.photos preview,
    Reminders, Copy and Add to Reading List.
  - Builds: Android `:app:compileDebugKotlin --offline` and an iOS
    simulator build.
- The census `TestTheQuestionsOnTheSharedRepositoryParse…` needed its
  quoted Go-file count bumped from 732 to 735 (repowalks_test.go and
  timings_test.go), because three new Go files were added.
