## How releases are cut here

There is no CHANGELOG, no version constant, and no GitHub Release. A release
is just an annotated tag whose message carries the summary. The shape, from
v0.4.0 and v0.5.0:

- a title line: `vX.Y.Z: <headline>`
- an API line: "No exported API removed since vA (N declarations added)"
- grouped bullets: Components (comps), Core, Natives, Behaviour change, Tooling

## What the pre-tag check found: master has been red for ~3 weeks

`gofmt -l .` and `go vet ./...` were clean. `gh run list --branch master`
showed both workflows failing, with neither failure on the Next list:

- **CI** (last green 2026-09-21, `Comps round four, phase 4`).
  `go test -race ./...` fails on `TestEditableGridBlurCommitsAfterTheGrace`
  and `TestEditableGridDiscardIsOneFocusUnitWithTheField`, and it reproduces
  locally (`go test -race -count=3 -run TestEditableGrid ./comps/`). Every
  racing pair runs through the harness's `OnChange` closure
  (`comps/editable_grid_test.go:68-78`). `gridSession.commit` runs on
  `UseTimeoutWhile`'s `time.AfterFunc` goroutine and calls that closure,
  which writes `g.rows`/`g.changes`. The test goroutine reads them after a
  `time.Sleep`, and a sleep does not order the two goroutines. The race is in
  the test harness, not in the grid. Because `go test -race` fails, the job
  skips the docs-server build, the WASM build and `wasm/verify/run.sh`.
- **site** (last green 2026-09-24). Browser check 24 (the overflow sweep)
  finds a Text or Checkbox overflowing its parent Row on tutorial lessons
  2.2, 4.29, 5.3, 6.5, 7.2 and 7.4, at 360 and/or 390px. The same lines
  appear in the 2026-10-05, 10-07 and 10-12 runs. Not run locally.

The user was given three options: fix the race and then tag (recommended),
fix both and then tag, or tag as-is. They chose **tag as-is**. Both failures
were recorded first (N-109, N-110), so the tag's known-issues section could

## API diff

`golang.org/x/exp/cmd/apidiff` was installed into the scratchpad, and v0.5.0
was checked out as a temporary worktree (removed afterwards). Each side was
exported with `apidiff -m -w`, then the two were diffed. 299 declarations
were added outside examples and internal (comps 142, core 128, htmlout 17,
hooks 5, mobile 2, render 1, permission 1, plus the new `keystore` and `blb`
packages). Three changes are incompatible:

- `core.ColorPalette.{Primary,Success,Warning,Error}OnLight` were removed,
  renamed to `*Ink` in c43e3bc when DarkTheme was bundled (N-074). The
  `*OnLightColor()` accessors remain as aliases.
- `core.ColorPalette` is no longer comparable, because it gained the `Chart`
  and `Sequential` slices.
- `examples/chat.MessageList` gained a typing flag and a reaction callback.

Unlike v0.4.0's message, this one could not say "No exported API removed", so
it has a "Breaking changes" section.
