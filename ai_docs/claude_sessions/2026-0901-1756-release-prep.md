## What changed

1. **Root `main.go` deleted.** It sat behind a `grmob` build tag, imported
   the nonexistent `myapp/app`, and failed `go vet -tags grmob .`. The
   README's Android step (`gomobile bind -tags grmob ./`) was the only
   reference; the real path is `android/build.sh`, which binds `./mobile`
   plus an app package.
2. **README rewritten where it had drifted.** Features line no longer says
   UseEffect is "soon"; Architecture lists every package and stops calling
   hooks "coming soon" / iOS "UIView (coming soon)"; Renderers says Compose,
   SwiftUI, DOM-via-WASM, htmlout; the build section mirrors
   docs/platforms/native.md (both build scripts); Dev Experience lists what
   exists; Hooks lists the real five. The example's `main.go` became
   `register.go` with `mobile.Register` in an `init`, and the two Buttons
   got handlers (core.Button requires one). The four snippets were
   extracted into a scratch module with a `replace` to the repo and
   `go vet`'d — they compile.
3. **`wasm/wasm_exec.js` refreshed** from the Go 1.26.1 toolchain
   (`$(go env GOROOT)/lib/wasm/wasm_exec.js`). The old copy dated from the
   first roadmap commit; 16 lines differed (globalThis.path shim,
   O_DIRECTORY, callExport). Keep doing this on toolchain bumps.
4. **gomobile pinned structurally.** `go mod tidy -diff` showed tidy would
   drop all four x/ requires despite the "do not drop" comment. go.mod now
   has a `tool` block (`golang.org/x/mobile/cmd/gomobile`, `.../gobind`),
   so tidy keeps them and `go tool gomobile` works. Comment updated.
5. **Go directive stays 1.26.1.** Tried `go 1.26`; tidy bumps it back
   because bytdb v0.11.0 requires >= 1.26.1. Docs' "Go 1.26+" left as is.
6. **ROADMAP:** packaging (`grmob build --target=...`) moved from
   In Progress to Planned, with a line naming today's equivalents.
7. **CHANGELOG.md added** — Keep-a-Changelog format, one 0.1.0 entry dated
   2026-09-01 summarizing the ROADMAP's Done list, link refs assuming a
   `v0.1.0` GitHub tag.
8. gofmt fixed the import grouping in `examples/todoapp/store.go`.
