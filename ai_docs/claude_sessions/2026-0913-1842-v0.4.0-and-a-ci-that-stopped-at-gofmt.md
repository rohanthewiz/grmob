  987e755 (08:49 today). The last green run was 3e16361.

## 5. What went wrong

- The first background CI wait used `gh run list --commit 7655b91`. It
  returned no run for the short SHA, so `gh run watch ""` failed with a 404,
  which looked like a CI failure. Selecting by `headSha | startswith(...)` from
  `gh run list --branch master --json` worked. For a tag run, select
  `headBranch == "v0.4.0"`.

## 6. Process notes

- **Before tagging, check the last CI run's jobs, not just that one job
  passes.** A workflow whose first step fails skips everything after it, so a
  red CI can hide weeks of unexecuted tests.
- A gofmt-only change can still stale `docs/api`, because the pages carry
  source line references. Regenerate after any edit to a documented file.
