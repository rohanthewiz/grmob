## Goal

Close the backlog item that has ridden along for seven sessions: `ROADMAP.md`
lists `UseMemo` and `UseReducer` as done and neither exists.

## What the ask turned into

The two hooks were the visible instance of a defect the file had in **fifteen
places, in both directions**. A roadmap that lists shipped work as "planned" is
as misleading as one listing absent work as done, so every checkbox was checked
against the source rather than only the line that prompted this.

Method: grep for the identifier, not for the prose. Each row below is a
`grep -rn` over `*.go` (widened to `*.kt`, `*.swift`, `*.js` where the claim was
about a renderer or the web bridge — which is what rescued `GoInvokeCallback`
from being wrongly deleted, since it lives only in `wasm/grmob-runtime.js`).

## Findings — listed as done, actually absent

| claim | reality |
|---|---|
| `UseMemo`, `UseReducer` | no definition anywhere; **this file was their only source** — `docs/` and `README.md` never promised them |
| `FlexRow`, `FlexColumn` | absent — the builders are `Row` / `Column` |
| Error boundaries and safe rendering fallback | **no `recover()` anywhere in the tree** |
| Component-scoped paths via `data-node-path` | absent — htmlout emits `data-onclick` / `data-onchange` / `data-ontoggle` |
| One-line hot reload with patch diffing | referenced in exactly two comments (`core/cleanup.go:17`, `render/manager.go:90`) as a *hypothetical host*, never implemented |

Three of those were never true and were removed. `UseMemo`/`UseReducer` and
error boundaries moved to **In Progress** — they are things someone might still
want, unlike a `data-node-path` attribute the exporter has no reason to grow.

Claims that survived the check and stayed: `UseInterval`, `UseTimeout`,
`PositionSticky`/`Absolute`/`Relative`, `ZIndex`, hover (via `PseudoStates`),
"internal path-based rendering IDs" (`reconcile.Patch.TargetID`, built from
`childPath` in `reconcile/patch.go:96`), and `window.GoInvokeCallback`.

## Two judgment calls worth flagging

- **Snapshot testing marked done.** The migration tests
  (`examples/todoapp/chip_migration_test.go`) pin a widget's exported markup to
  the hand-rolled original byte for byte, which is what that line meant.
- **"Forms with validation" left open.** `FormField` renders an `Error`, but
  nothing in the tree validates anything. Rendering the affordance is not the
  feature.

Also folded in the four renderer gaps the session notes have been carrying, so
they live in the roadmap rather than only in `ai_docs`: proportional flex
weights on iOS, `AlignItems: "stretch"`, a `ContentMode` prop on `Image`, and a

## Method note worth keeping

**A roadmap decays in both directions, and the "shipped but still listed as
planned" half is the easier one to miss** — nobody is annoyed by it, so nobody
reports it. Auditing only the direction someone complained about would have left
ten shipped features looking unbuilt, including both native runtimes. When one
checkbox is found wrong, the cheap move is to check all of them.
