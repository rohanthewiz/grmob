## 3. The shape question: ZStack layer, not Modal

Read the four Modal hosts before building:

| Target | Modal presents as | Leading panel possible? |
|---|---|---|
| web ×2 | fixed overlay, flex column, centred (`modalChassisDecls`, runtime `styleFromGrMob`) | yes, a Row filling it |
| Compose | `Dialog` at platform default width, `Column(fillMaxWidth).padding(8)` | only inside a centred window |
| SwiftUI | `.sheet`, detents medium/large | a bottom sheet |

A `ZStack` is a single-cell grid on the web, a `Box` on Compose and
`GrMobStackLayout` on SwiftUI; a `"100%"` layer fills it on each
(`dimensionModifier` → `fillMaxWidth/Height(fraction)`; Swift `"100%"` →
max infinity). Both natives treat `Display none` as "do not compose"
(`Renderer.kt:162`, `Renderer.swift:59`). So the plan's original sketch was
right, now for a reason found after B1.

Costs of dropping the Modal chassis, and what was done:

- Screen-reader confinement → content layer takes `AccessibilityHidden` while
  open (the a11y audit has no hidden-but-focusable concern, checked).
- Focus → `Drawer.CloseRef` stamps the ✕; the opener calls `core.Focus`.
  `OnDismiss` can refocus the ☰ through the new `Button.FocusRef`.
- Web Tab containment → **not fixed**: no `inert` in core; the web runtime has
  no Escape or focus trap for Modals either.
- Android back button → **not wired**: no back-press hook in core.
- `MaxWidth` has no Compose mapping (grep), so the panel uses `Width`
  (default `280px`; percentages are honoured on all four).

## 4. `comps.Drawer` (`comps/drawer.go`)

- `ZStack(Width 100%, Style…) > [Box 100%×100% (AccessibilityHidden if Open) >
  Content, Row(Padding 0, Gap 0, AlignItems stretch, 100%×100%, Display none
  if shut) > [panel Column, scrim Box]]`.
- Panel: `Width` (default 280px), `Height 100%` (SwiftUI HStack doesn't
  stretch unasked), `Colors.Background`, `Padding SM`, `Gap XS`,
  `RoleNavigation` + `AccessibilityLabel(Title)`, then `PanelStyle`.
- Header Row: growing Box with Title (`Typography.Subtitle`, bold,
  `Colors.TextPrimary` — Subtitle alone rendered grey in the first shot) and a
  ghost ✕ `Button` named `CloseLabel` / `"Close " + Title` /
  `"Close navigation"`, carrying `FocusRef: CloseRef`. No ✕ when `OnDismiss`
  is nil; header omitted when there is neither title nor ✕.
- Rows: `ListRow{Leading: icon (hidden), Title, Subtitle, OnTap: pick,
  Selected, AccessibilityLabel: Label}`. **Gotcha:** ListRow appends
  ", selected" only to an explicit `AccessibilityLabel`, so the label is
  restated.
- `pick` = item `OnTap` then `OnDismiss`. `Selected` follows BottomBar: zero
  selects the first, negative none. `Body` replaces the rows.
- Scrim: `FlexGrow 1`, `Height 100%`, `Backdrop` or `#00000088`
  (Modal's default, restated as `drawerDefaultBackdrop`),
  `AccessibilityHidden`, `OnClick` only when `OnDismiss` is set.
- Only the shut state writes `Display`, so the Row's flex comes back on the
  web's total style pass.
- No hooks.
- Tests `comps/drawer_test.go`: shut shape and landmark, open hides screen,
  same tree shape open/shut, pick→dismiss order and selected name, negative
  Selected, ✕ + scrim dismiss, nil OnDismiss, CloseLabel fallbacks, Body,
  styles reach nodes, CloseRef takes a focus command. **Gotcha:** a two-pass
  focus fixture needs `ctx.Reset()` after `BeginRenderPass` or `UseFocusRef`
  returns a new ref.
